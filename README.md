# 支持按流量计费（不限时流量包推荐）

对于低频使用、备用需求、多设备场景，或不希望每月流量重置的用户，按流量计费（不限时）方案通常比传统月付套餐更灵活——可能更省钱。

## 为什么选择不限时流量包？

### 速度更快

原因很简单，机场主巴不得你尽快用完，速度给你充足保障。很多机场针对不同的套餐等级会限速，但是他们最不可能限速的就是不限时套餐。

### 更适合低频用户

如果仅偶尔使用，月付套餐往往会产生大量未使用流量，而按量套餐通常采用“用完为止”模式，无需担心月底清零。

虽然不限时的套餐性价比不如月付套餐，但是对低频上外网用户友好，对于他们来说实际上更省钱。

### 更适合长期备用

购买后无需持续续费，只要服务仍在运营且套餐有效，即可在未来继续使用剩余流量。

### 多设备使用更灵活

大多数服务商允许不限时套餐支持更多设备同时在线，适合作为家庭、办公或多终端备用网络方案。

### 预算可控

一次付费后无需关注续费周期，更容易控制长期使用成本。
